پروژه فروشگاه تجهیزات و کالای برق اداوی
====================================

اجرا:
1) فایل ZIP را کامل Extract کنید.
2) فایل .env.example را کپی و نام نسخه کپی را دقیقاً .env.local بگذارید.
3) در .env.local آدرس پروژه Supabase و Publishable key یا anon key را وارد کنید.
4) در همین پوشه ترمینال باز کنید و اجرا کنید:
   npm install
   npm run dev
5) آدرس نمایش‌داده‌شده توسط Vite را باز کنید.

فروشگاه عمومی: آدرس اصلی /
پنل مدیریت: /admin.html

ورود پنل:
از ایمیل و رمز عبور کاربر مدیر در Supabase Authentication استفاده کنید.
پنل فقط UID زیر را می‌پذیرد:
d9254d7d-6639-488d-83d6-ed1c508c495e

امکانات پنل:
- افزودن، ویرایش و حذف محصول
- تغییر قیمت، موجودی، دسته‌بندی، توضیحات و وضعیت نمایش
- بارگذاری تصویر محصول در bucket با نام store-images
- افزودن، ویرایش و حذف نمونه‌کارها و بارگذاری تصویر

نکات مهم:
- این پروژه از کلید عمومی (Publishable/anon) استفاده می‌کند؛ هرگز service_role/secret key را در مرورگر قرار ندهید.
- امنیت نهایی باید با RLS در Supabase اعمال شود؛ کنترل UID در رابط پنل به‌تنهایی جایگزین RLS نیست.
- مطمئن شوید برای جدول‌های products و portfolio سیاست‌های SELECT عمومی فقط برای is_active=true و INSERT/UPDATE/DELETE فقط برای UID مدیر فعال‌اند.
- برای Storage bucket با نام store-images، دسترسی خواندن عمومی و نوشتن/حذف فقط برای UID مدیر لازم است.
- عکس‌ها در این نسخه تا ۵ مگابایت پذیرفته می‌شوند.
- پنل در فایل admin.html مستقل است و در صفحه عمومی لینک مدیریتی نمایش داده نمی‌شود.
- این بسته از نظر نحوی بررسی شده؛ اتصال واقعی به پروژه Supabase و اجرای مرورگر روی دستگاه شما باید پس از نصب بررسی شود.
